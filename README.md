Project Overview : -
In this project, I implemented and compared the following models:
✅ Linear Regression
✅ Logistic Regression (used for classification-based framing)
✅ Decision Tree Regressor

The project covers the complete pipeline including:

Data loading
Exploratory Data Analysis (EDA)
Data preprocessing and scaling
Model training
Model evaluation
Prediction on new/unseen data

Tech Stack:-
Programming Language: 
Python
Libraries:
pandas
numpy
scikit-learn
matplotlib / seaborn (optional for visualization)
streamlit (optional for UI, if used)

Model Evaluation:-
The models were evaluated using:

📌 Mean Squared Error (for regression models)
📌 R² Score
📌 Comparison between Linear Regression and Decision Tree Regressor

This helped in understanding:

Model performance
Underfitting vs Overfitting
Bias–Variance tradeoff

Key Learnings

How to build an end-to-end ML pipeline
Importance of feature scaling in ML
Model selection based on problem type
How different algorithms behave on the same dataset
Saving and loading trained models using pickle
