# 🤖 Machine Learning Model Comparison Project

## 📌 Project Overview

In this project, I implemented and compared the following models:

✅ Linear Regression  
✅ Logistic Regression (used for classification-based framing)  
✅ Decision Tree Regressor  

The project covers a complete end-to-end Machine Learning pipeline including:

- Data Loading  
- Exploratory Data Analysis (EDA)  
- Data Preprocessing & Feature Scaling  
- Model Training  
- Model Evaluation  
- Prediction on New/Unseen Data

## 📊 Model Evaluation

The models were evaluated using:

📌 Mean Squared Error (MSE) – for regression models  
📌 R² Score  
📌 Performance comparison between Linear Regression and Decision Tree Regressor  

This helped in understanding:

- Model performance comparison  
- Underfitting vs Overfitting  
- Bias–Variance Tradeoff

- How to build an end-to-end ML pipeline  
- Importance of feature scaling in Machine Learning  
- Model selection based on problem type
